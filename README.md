# ממיר PDF ל-DXF לחיתוך בלייזר

כלי דפדפן שממיר PDF וקטורי ל-DXF R12 עבור RDWorks / LaserCut.
רץ במלואו בצד הלקוח — הקבצים לא עוזבים את המחשב, אין שרת.

## שימוש

גרור PDF, בדוק את התצוגה המקדימה, קבע רוחב במ"מ אם צריך, הורד DXF.

בתצוגה: **שחור = נתיב סגור**, **אדום = נתיב פתוח**. נתיב פתוח לא ייחתך כצורה
סגורה, וזו הסיבה הנפוצה ביותר לתוצאה לא צפויה בלייזר.

## איך זה עובד

MuPDF (WASM) מרנדר את העמוד ל-SVG, ומשם מחלצים פוליליינים במילימטרים.
המסלול דרך SVG ולא דרך קריאות ה-device של MuPDF נבחר כי בניית ה-WASM לא
מייצאת `fz_outline_glyph` — דרך SVG, **טקסט חי מומר לקווי מתאר אוטומטית**.

עקומות בזייר משוטחות לפוליליינים בסבילות 0.05 מ"מ. הפלט הוא DXF R12 (`AC1009`)
עם `POLYLINE`/`VERTEX`/`SEQEND` בלבד — בלי `LWPOLYLINE`, בלי `SPLINE`, בלי בלוקים.
DXF חסר יחידות; RDWorks מניחה מ"מ.

## מגבלות ידועות

- עמוד ראשון בלבד (מוצגת התראה אם יש יותר).
- נתיבי חיתוך (clipping) מתעלמים — ייתכנו וקטורים מחוץ לאזור הנראה.
- PDF סרוק (תמונה בתוך עטיפה) לא נתמך; תוצג הודעה שלא נמצאו וקטורים.
- מילוי וקו מתאר של אותו נתיב ייוצאו כשני נתיבים. אם זה יקרה בקובץ אמיתי,
  ספירת הנתיבים בתצוגה תסגיר את זה ונוסיף dedupe.
- הכל יוצא לשכבה `0`. פיצול שכבות לפי צבע עדיין לא ממומש.

## בדיקה

פתח `test.html` בדפדפן (דרך שרת, לא `file://`). 12 בדיקות על שיטוח
הבזיירים, המרת היחידות וכתיבת ה-DXF.

```bash
npx http-server -p 8111 .
```

שהמקור יהיה זמין. בריפו ציבורי זה מתקיים ממילא.
